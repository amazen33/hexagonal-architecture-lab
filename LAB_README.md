# 🏗️ Hexagonal Architecture Lab

## Welcome to the Hexagonal Architecture Hands-on Lab!

This repository contains a complete, production-ready implementation of a hexagonal architecture (ports and adapters) project. Use this as a learning resource or as a template for your own projects.

## 📋 Prerequisites

- Java 17 or higher
- Maven 3.8+
- Your favorite IDE (IntelliJ, Eclipse, VS Code)
- Basic understanding of Spring Boot

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/amazen33/hexagonal-architecture-lab.git

# Navigate to project
cd hexagonal-architecture-lab

# Build the project
./mvnw clean install

# Run the application
./mvnw spring-boot:run

📚 Lab Exercises
Exercise 1: Domain Model Enhancement
Add a new Address value object to the User entity with validation rules.

Exercise 2: Create New Use Case
Implement an UpdateUserUseCase that allows updating user information.

Exercise 3: Add New Adapter
Create a MongoDB adapter for the UserRepository.

Exercise 4: Write Tests
Write unit tests for the CreateUserService use case.

🎯 Learning Path
Beginner: Understand the folder structure and READMEs

Intermediate: Implement the exercises above

Advanced: Add new features following the architecture
